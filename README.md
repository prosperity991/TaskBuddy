TaskBuddy Documentation 

Overview 

TaskBuddy is a fun and engaging mobile application designed to help users' separate facts from fiction by answering a series of questions. The app presents users with statements or situations, and the user must determine if the statement is a "hack" (a useful tip or shortcut) or a "myth" (a widely held but false belief). The goal is to challenge users' knowledge, spark curiosity, and provide fun, informative content on various topics. 

Key Features 

Question Presentation: The app presents a series of questions where users are asked to choose whether the statement is a "hack" or a "myth." 

Instant Feedback: After submitting an answer, users will receive immediate feedback indicating whether their answer was correct or incorrect. 

Varied Categories: Questions come from a wide range of topics, including life hacks, productivity tips, health myths, and tech tricks. 

Leaderboard: The app includes a leaderboard to encourage friendly competition and reward users with the highest scores. 

User Flow 

Start Screen: When users first launch the app, they are greeted with a simple interface showing a "Start" button. 

Question Screen: Once the user clicks "Start," they are taken to a screen that displays a question. Each question includes: 

A statement or situation. 

Two options: "Hack" or "Myth." 

A timer (optional) for added challenges. 

Answer Selection: Users select one of the two options (Hack or Myth) to answer the question. 

Feedback: After answering, users receive immediate feedback, telling them whether their choice was correct. 

If correct: A message congratulating the user and a brief explanation of the correct answer. 

If incorrect: A message informing the user of the mistake, along with a brief explanation of the correct answer. 

Continue or Exit: Users can choose to continue to the next question or exit the app.
